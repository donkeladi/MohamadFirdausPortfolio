# Mohamad Firdaus, Portfolio

Laman portfolio statik (HTML, CSS dan JS biasa). Tiada langkah binaan diperlukan.

Alamat selepas GitHub Pages diaktifkan: https://donkeladi.github.io/MohamadFirdausPortfolio/

## Aktifkan GitHub Pages
1. Buka Settings, kemudian Pages.
2. Di bawah Build and deployment, pilih Source: Deploy from a branch.
3. Pilih branch yang mengandungi `index.html` dan folder `/ (root)`, kemudian Save.
4. Tunggu 1 hingga 2 minit.

## Statistik pelawat (pilihan)
Daftar akaun percuma di goatcounter.com, kemudian isi kod di `index.html`:
`const CONFIG={goatcounter:'kod-anda'};`

## Struktur
- `index.html`: keseluruhan laman, termasuk gaya dan skrip
- `assets/`: gambar, video dan kad kongsi (`og.jpg`)
- `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`
